# AI 工作流 SOP 通用規範

此文件定義了通用 AI 工作流標準操作流程 (SOP)，適用於多種開發任務。框架特定規範請參考對應文件。

## 1. AI 工具使用規範

- **工具整合**：優先使用 Gemini、Claude、Codex 等 AI 工具輔助開發。
- **品質保障**：AI 生成代碼必須經人工審核，避免過度依賴。
- **記錄要求**：記錄 AI 互動過程，包括提示詞、生成結果與修改理由。

## 2. 開發流程規範

- **階段性執行**：遵循規劃、開發、測試、報告的順序。
- **版本控制**：使用 Git 管理代碼，提交訊息清晰描述變更。
- **測試優先**：自動化測試覆蓋率至少 80%。

## 3. 程式碼風格通用原則

- **命名慣例**：使用駝峰式 (camelCase) ，避免縮寫。
- **註釋要求**：關鍵邏輯添加註釋，說明目的與邏輯。
- **錯誤處理**：統一使用 try-catch 或等效機制。

## 4. 框架特定規範

- **Vue3**：參考 `vue3-rules.md`。
- **其他框架**：未來可添加對應文件，如 `react-rules.md`、`node-rules.md`。

## 5. 報告與回顧標準

每次任務完成後，產出報告包含：

- **任務摘要**：條列完成項目。
- **AI 使用記錄**：列出使用的 AI 工具與貢獻。
- **品質檢查**：確認符合通用規範與框架特定規則。

### 檢查清單 (AI Review 用)

- [ ] AI 工具使用是否記錄？
- [ ] 代碼品質是否通過審核？
- [ ] 測試是否覆蓋關鍵路徑？
- [ ] 報告是否完整？
